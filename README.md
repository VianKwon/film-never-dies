# Film Never Dies 🎞️

A project dedicated to **physical film** preservation and digital archiving.

## Project Overview

This project aims to preserve analog film heritage through digital technologies and modern archiving techniques. Focus on **film reels, negatives, and photographic film** preservation.

## Features

- Physical film condition assessment
- Film metadata and inventory management
- Digital scanning workflow
- Archival database for film collections

## Getting Started
