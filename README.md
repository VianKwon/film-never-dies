# 🎞️ Film Never Dies - Web App

A modern web application for recording and managing your film photography.

## Features

- 📝 **Add Film Records** - Track film type, ISO, camera, dates, notes
- 📋 **Organize Collection** - Filter by film type (35mm, 120, etc.)
- 📊 **Statistics** - View usage statistics and trends
- 💾 **Data Management** - Export/Import your film data
- 📱 **Mobile-Friendly** - Works on all devices
- 🔒 **Local Storage** - Your data stays on your device
- 🖨️ **Print Support** - Print your film records

## How to Use

### Online Version
Visit: `https://vianKwon.github.io/film-never-dies/`

### Local Usage
1. Download all files
2. Open `index.html` in your browser
3. Start adding film records!

## Data Storage

All film data is stored in your browser's **localStorage**. This means:
- ✅ Your data stays private
- ✅ No internet required after loading
- ✅ Data persists between sessions

To backup your data:
1. Click "Export Data" in the footer
2. Copy the JSON data
3. Save it somewhere safe

## Browser Support

Works on all modern browsers:
- Chrome/Edge (recommended)
- Firefox
- Safari
- Mobile browsers

## Offline Usage

The app works offline after the first load. You can:
- Add new film records offline
- View existing records
- Export data

## Adding to Home Screen (Mobile)

1. Open the app in Safari/Chrome
2. Tap the share button
3. Select "Add to Home Screen"
4. Use it like a native app!

## Development

To modify the app:
- `index.html` - Main HTML structure
- `style.css` - Styles and layout
- `app.js` - All functionality
- `manifest.json` - App configuration
