# Project Architecture



## Overview

This project helps preserve physical film reels through digital technology.



## Main Components



### 1. Film Database

- Stores film information

- Tracks film condition

- Manages film types (8mm, 16mm, 35mm)



### 2. Preservation Tools

- Add new films

- List all films

- Get statistics



### 3. File Structure




film-never-dies/
├── src/sample.js      # Main film tools
├── tests/             # Test files
├── docs/              # Documentation
├── index.js           # Main program
├── package.json       # Project config
└── README.md          # Project info


## How It Works

1. **Add films** - Store film details
2. **Track condition** - Monitor film state
3. **Generate reports** - Get statistics
